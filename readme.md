
# Команды Git

git init - инициализирует новый локальный репозиторий
git add <file> - добавляет файл в индекс (staging area)
git commit -m "message" - создает коммит с сообщением
git status - показывает состояние рабочего каталога и индекса
git log - показывает историю коммитов
git branch <branch_name> - создает новую ветку
git checkout <branch_name> - переключается на указанную ветку
git merge <branch_name> - сливает указанную ветку в текущую
git clone <url> - создает локальную копию удаленного репозитория
git push - отправляет изменения в удаленный репозиторий
git pull - загружает изменения из удаленного репозитория и сливает их
